# Claw

The DIY two-finger gripper that speaks the same HTTP/cord protocol as the Brunel Hand. `software/firmware` is
the Pico W firmware (built, not yet run on hardware). `hardware/` is empty on purpose: the v1 OpenSCAD design
(gear-driven fin-ray fingers) was retired; the rebuild will be direct-drive in build123d with measured parts
(STS3215 + horn, driver board, 2S pack, BMS, buck, USB-C charger), printed in PETG with TPU fingers.
